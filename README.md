# Phantom-Macro

My first attempt on macropad!. Ofc I have to make it stand out among the 1000s of different macropads. I decided to make it modular in a way where u can daisy chain macropads together to your liking and make a keyboard out of it or anything that suits. It's also my first ever attempt on using hall-effect switches. Can't forget RGB makes everything cooler I think.

## Features 

### Daisy-chainable
Use pogo wires or snapping the macropads together using the pogo connectors

### Customizable (macropad)
Can be made in any layout as long as all the essential mcu components and the connectors part are made the same for every macropad.

### Customizable (Layout)
Can be connected with any macropads that uses the same internal components and pogo connectors. (So far there is only 1 macropad, gonna work on more soon)
